# Security Policy

## Supported Versions

This project is in initial development. Security fixes apply to the current main branch until tagged releases are published.

## Reporting a Vulnerability

Please report suspected security issues through a private maintainer channel when available. Do not open public issues containing exploitable details, credentials, tokens, or private screenshots.

## Sensitive Data Rules

- Do not commit private user screenshots.
- Do not commit API keys, tokens, cookies, session exports, or browser profiles.
- Do not commit official lottery screenshots, logos, or copied page assets.
- Do not add code that bypasses anti-crawling, CAPTCHA, access-control, security, or risk-control mechanisms.

## Scope Boundary

This repository is for non-official simulation and review workflows only. Vulnerability reports about real lottery purchase flows, payment flows, ticket issuing, or following-order services are out of scope because those capabilities must not exist in this project.
