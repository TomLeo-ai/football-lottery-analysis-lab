# 合规边界

本项目是非官方、仅用于技术研究和模拟复盘的开源实验室，不构成购彩建议、收益承诺或中奖保证。

## 负责任使用

- 本项目不面向未成年人，不得引导未成年人参与彩票或其他博彩活动。
- 不得使用本项目的模拟输出进行真实投注、购彩或其他财务决策。
- 使用者应自行确认并遵守其所在地适用的法律法规和平台规则。

## 禁止能力

- 禁止实现真实购彩、支付、出票、代购、合买、跟单、充值、提现。
- 禁止抓取、缓存、镜像或再发布中国竞彩网、中国体育彩票或其他官方彩票页面数据。
- 禁止内嵌官方页面、复制官方页面素材、提交官方截图或官方 Logo。
- 禁止提交真实官方批量赛事、赔率、开奖、赛果数据。
- 禁止提供绕过反爬、验证码、安全策略或风控机制的代码。
- 禁止把 OCR 识别结果作为公共官方数据源发布。
- 禁止输出“必中、稳赚、包中、回本、跟投、实单推荐、加注”等高风险宣传文案。
- 禁止把大模型包装成实单工具、确定性预测工具或自动跟单工具。
- 禁止将 API Key 写入数据库、日志、Prompt、前端响应或审计明细。

## 允许能力

- 维护官方信息的外部链接入口，并展示用途说明和非官方声明。
- 接收用户上传的虚构或用户自有截图，用于本地 OCR 和人工确认。
- 基于用户确认后的结构化快照生成模拟分析报告。
- 保存模拟方案和生成时快照，用于后续复盘。
- 使用合规公开体育比分源、赛事官网公开比分、用户自配授权 API 或 Mock 赛果源进行复盘。
- 在用户显式选择时，通过后端环境变量接入 OpenAI-compatible 模型生成结构化模拟分析。
- 在规则引擎完成结算后，通过大模型生成解释性复盘洞察，但不得改写规则结算状态。

## 数据原则

所有示例数据必须显著标注 `DEMO DATA / FICTIONAL SAMPLE`。任何赛前输入都必须经过用户确认，确认后的 `sourceType` 必须为 `USER_SCREENSHOT_CONFIRMED`。

分析、模拟方案和复盘记录都必须保存当时使用的 `strategyParameters` 快照。复盘必须使用历史方案保存的参数快照，不能用当前页面默认值覆盖历史方案。

大模型调用审计写入 `llm_invocation_audit`，只记录业务类型、业务 ID、provider、model、promptVersion、inputHash、outputHash、tokenUsage、latencyMs、safetyStatus、errorCode 和创建时间。审计记录不得包含密钥、完整 Prompt、原始截图或模型输出正文。

## 页面声明要求

README、Dashboard、AI 报告、模拟方案页、复盘页必须展示非官方声明和“仅模拟分析/复盘”提示。

模型设置页必须展示 API Key 前端不可见、密钥只由后端环境变量读取、缺少密钥时规则引擎仍可完整运行。

## 大模型边界

- 默认分析方式是 `MOCK_RULE_ENGINE`。
- 默认复盘方式是 `RULE_REVIEW_ONLY`。
- 大模型预测模式是 `OPENAI_COMPATIBLE`，只在显式选择并配置 Provider 密钥后调用。
- 大模型复盘洞察模式是 `RULE_REVIEW_WITH_LLM_INSIGHT`，只解释规则结算结果。
- `LlmOutputValidator` 和 `SafetyGuardService` 是可用输出的强制门禁。
- `safetyStatus=BLOCKED` 的输出不得保存为可用报告或可用洞察。
