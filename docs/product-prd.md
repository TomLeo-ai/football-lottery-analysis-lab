# 产品概要

## 产品定位

Football Lottery Analysis Lab 是非官方、开源、模拟分析与赛后复盘实验室。它帮助开发者研究 OCR、结构化快照、模拟方案保存、公开赛果匹配和复盘归因流程。

## 核心功能

1. 官方信息外链入口，不展示官方具体数据。
2. 虚构截图上传、本地 OCR 和人工确认。
3. 基于用户确认快照的 Mock AI 分析。
4. 模拟方案生成、保存和不可变快照。
5. Mock 公开赛果同步、自动匹配、结算与复盘。

## 首版页面

- Dashboard
- OfficialSourceHub
- ScreenshotUpload
- OcrReviewWizard
- MatchWorkspace
- StrategySimulator
- SavedPlans
- ReviewCenter
- StrategyLab
- AboutCompliance

## 成功标准

- 前后端可以本地启动。
- 主流程可以用虚构数据跑通。
- 自动化测试、构建和合规扫描通过。
- 页面和文档均展示非官方、仅模拟分析/复盘声明。
